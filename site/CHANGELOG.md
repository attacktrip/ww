# Changelog - Обновление дизайна и структуры

## Изменения от 2026-02-09

### 🎨 Дизайн

#### Цветовая палитра
- ❌ Удалены все цветные акценты (розовый, фиолетовый)
- ✅ Используется только черно-белая палитра с оттенками серого
- ✅ Добавлены эффекты прозрачности, стеклянных слоев, blur
- ✅ Подсветки белым светом вместо цветных

#### Иконки
- ❌ Удалены все эмодзи из интерфейса
- ✅ Добавлены SVG иконки в стиле SF Symbols (iOS)
- ✅ Все иконки монохромные (черно-белые)
- ✅ Создан файл `js/icons.js` с библиотекой иконок

### 🧱 Структура страниц

#### Новая структура
- `index.html` - Landing страница (гостевая, без авторизации)
- `app.html` - Приложение гаранта (с Telegram.WebApp интеграцией)

#### Landing страница (`index.html`)
- Крупный заголовок
- Описание сервиса безопасных сделок
- Объяснение работы через Telegram
- Описание процесса сделки
- Блок преимуществ
- Кнопка "Открыть сервис" для перехода на app.html

#### Приложение (`app.html`)
- Инициализация Telegram.WebApp
- Получение данных пользователя
- Все функции приложения
- Автоматический вызов `first_join()` при первом входе

### 📝 Изменения в файлах

#### CSS (`css/style.css`)
- Обновлена цветовая палитра (только черно-белая)
- Убраны градиенты с цветами
- Обновлены эффекты свечения (белый свет)
- Добавлены стили для landing страницы
- Обновлены стили для иконок

#### JavaScript (`js/app.js`)
- Удалены все эмодзи из текстов
- Добавлена функция `insertIcons()` для вставки SVG иконок
- Обновлены все функции, создающие HTML с иконками
- Автоматическая вставка иконок в модальных окнах

#### Новые файлы
- `js/icons.js` - библиотека SVG иконок в стиле SF Symbols
- `index.html` - landing страница
- `app.html` - приложение (переименовано из index.html)

### 🔄 Логика работы

#### Landing страница
- Не требует авторизации
- Не обращается к backend
- Не использует Telegram API
- Статическая информация о сервисе

#### Приложение
- Инициализирует Telegram.WebApp только на странице app.html
- Получает данные пользователя из `Telegram.WebApp.initDataUnsafe.user`
- Автоматически вызывает `first_join()` при первом входе
- Все функции работают как раньше

- Все API endpoints работают как раньше
- Все функции бота реализованы
