# Telegram Mini App - Гарант-Бот

## 📋 Описание проекта

Полнофункциональный веб-интерфейс для Telegram-бота-гаранта, выполненный в современном стиле iOS 26 с эффектами liquid glass и glassmorphism.

## ✨ Основные возможности

### Пользовательские функции
- 👤 **Профиль** - просмотр ID, баланса, количества сделок, СБП
- 💵 **Прошедшие сделки** - история сделок как продавца и покупателя
- 🔒 **Проведение сделок** - создание новых сделок с выбором роли
- 💰 **Управление балансом** - пополнение и вывод средств
- ⭐️ **Информация** - контакты и инструкции

### Функции сделок
- ✅ Принятие/отклонение предложений о сделке
- 💳 Оплата товара
- 📝 Установка цены товара (для продавца)
- ✅ Подтверждение получения товара
- ⚠️ Открытие споров
- ❌ Отмена сделок
- ⭐ Отзывы о сделках

### Управление профилем
- 🔄 Обновление логина
- 📱 Изменение номера СБП
- 💸 Вывод средств
- 💰 Пополнение баланса

## 🎨 Дизайн

- **Стиль**: iOS 26 / Liquid Glass / Glassmorphism
- **Цветовая схема**: Черно-белая палитра с розовым акцентом
- **Эффекты**: Размытие, прозрачность, мягкое свечение
- **Анимации**: Плавные переходы и появления элементов
- **Адаптивность**: Полностью адаптивный дизайн для мобильных устройств

## 🏗️ Архитектура

### Backend (Flask)
- RESTful API
- Интеграция с существующими функциями бота
- Работа с той же базой данных
- CORS для работы с Telegram Mini Apps

### Frontend
- Vanilla JavaScript (без фреймворков)
- Telegram.WebApp интеграция
- Модальные окна вместо стандартных alert/prompt
- Обработка ошибок на всех уровнях

## 🔌 API Endpoints

Всего реализовано **15+ эндпоинтов**:

- `GET /api/profile` - Профиль пользователя
- `GET /api/deals` - Прошедшие сделки
- `GET /api/deal_info` - Информация о текущей сделке
- `GET /api/about` - Информация о боте
- `GET /api/reviews` - Отзывы
- `POST /api/start_deal` - Начать сделку
- `POST /api/accept` - Принять сделку
- `POST /api/cancel` - Отменить сделку
- `POST /api/pay` - Оплатить товар
- `POST /api/dispute` - Открыть спор
- `POST /api/review` - Добавить отзыв
- `POST /api/replenish` - Пополнить баланс
- `POST /api/check_payment` - Проверить оплату
- `POST /api/output` - Вывод средств
- `POST /api/update_qiwi` - Обновить СБП
- `POST /api/update_login` - Обновить логин
- `POST /api/confirm_receipt` - Подтвердить получение
- `POST /api/set_price` - Установить цену

## 🚀 Быстрый старт

1. Установите зависимости: `pip install -r requirements.txt`
2. Запустите backend: `python backend/app.py`
3. Откройте `frontend/index.html` в браузере
4. Для Telegram: разместите на HTTPS и настройте через @BotFather
